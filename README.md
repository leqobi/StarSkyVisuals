# StarSkyVisuals
✨ StarSkyVisuals — бесплатный визуальный мод для Minecraft 1.21.11 (Fabric). Частицы удара, цифры урона, эффекты крита, траектория стрел, Target HUD, кастомный прицел, China Hat, Jump Circle и Dynamic Island — всё как в платных визуалах, но без читерских модулей и без единого рубля.
